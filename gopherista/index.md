# Gopherista

Write and run Go on your iPhone and iPad.

## Support

Email me@ryd.cx and I'll get back to you as soon as I can.

**I bought the Full Version but don't have it.** Open Settings (the gear) → Full Version → Restore Purchases, signed in with the Apple Account you bought it with. If that doesn't help, email me the Order ID from Apple's receipt email.

**What does the free trial include?** Running your own scripts, for 14 days from when you start it. After that, running scripts from the editor needs the Full Version, a one-time purchase. Writing scripts, reading the documentation and running its examples stay free.

**How do I get a refund?** Apple handles refunds at reportaproblem.apple.com.

**Which Go does it run?** Scripts run in yaegi, a Go interpreter that supports Go 1.20, generics included. Features added after 1.20, like min and max, range over an int, and the slices, maps and cmp packages, aren't available, and neither are cgo, unsafe, syscall or os/exec.

**Where are my scripts?** In the Files app, under On My iPhone (or On My iPad) → Gopherista.
